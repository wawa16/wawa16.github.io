Motor control & fault recovery

CAN-based motor software with emergency stopping, fault feedback, and recovery behavior.

  • CAN bus
  • SocketCAN
  • Linux
  • Motor control

Project context

I developed motor control software for an autonomous vehicle, with an emphasis on fault handling and controlled recovery.

My contributions

  • Implemented emergency stop functionality and motor fault reporting.
  • Developed recovery procedures and message priorities using CAN arbitration and filtering.
  • Used Linux SocketCAN for communication between the PC application and motor system.
  • Established communication between the motor application and PLC firmware.
