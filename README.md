- Haptic Feedback Glove
- Pneumatic Mechanism for VR

- DC-Cellbot Surveillance Bot
- Light Follower Three Wheeler

- CCNA Frame-relay Network

## Website

Open `index.html` locally, or serve this directory with a static web server. No build step or package installation is required. Relative links support both account and project sites on GitHub Pages.

The site uses local images and styles. Video demonstrations and publications are linked externally. No analytics, external fonts, or tracking embeds are included.

## Editing

Edit the HTML pages and `style.css`. Project media is stored under `assets/`. Keep image paths relative to the page. Publish this folder only; application records and source archives are not part of the website.
